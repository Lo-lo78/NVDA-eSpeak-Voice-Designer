eSpeak Voice Designer

eSpeak Voice Designer is an accessible real-time editor for the eSpeak NG synthesizer included with NVDA. It edits normal eSpeak voice/variant parameters while you listen to the result.

Opening the Designer

Press NVDA+Alt+V. If another synthesizer is active, the add-on switches to eSpeak NG only while the Designer is open. If a persistent draft exists, it is resumed automatically; otherwise the current eSpeak sound is read as the starting point. The NVDA eSpeak variants selector has no New variant item and starts with no selection; it is only a clean starting-source picker. Saved variants keeps the New variant state for unsaved personal work.

Draft and closing

Enter/OK stores the current Modified state as a persistent draft and closes the Designer. The draft survives NVDA and Windows restarts and is resumed the next time the Designer opens. The title shows the literal word Modified whenever the current source is not a clean saved personal variant: a standard/native eSpeak source starts as Modified, and a saved personal variant becomes Modified as soon as it is edited. Esc/Cancel discards only changes made during the current opening; an older draft that existed before opening remains available. In both cases NVDA returns to the synthesizer and eSpeak voice/variant it was using before the Designer opened. Choosing another factory/native or saved variant discards the old draft. Ctrl+S saves the current work as a personal variant and removes the Modified state.

Global navigation

  • Alt+S: Section.
  • Alt+V: cycle focus between NVDA eSpeak variants and Saved variants.
  • Alt+L: first parameter of the current section.
  • Alt+P: preview.
  • Alt+E: move to Preview text.
  • Alt+N: move to Variant name.
  • Alt+H: this help.
  • Ctrl+S: Save variant as.
  • Ctrl+Shift+S: install the current saved personal variant in NVDA's native eSpeak variants folder only while it is clean (no Modified in the title). Windows may request administrator permission.
  • Ctrl+Delete: restore the current editing base.
  • F2 on Saved variants: rename the selected personal file.
  • Delete on Saved variants: delete the selected personal file after confirmation.

Textual combo boxes support alphanumeric type-ahead. Repeating the same initial cycles through matching items.

Editing values

Arrow Up/Down changes numeric parameters by the small step; Page Up/Down uses the larger step. The live voice is applied before NVDA announces the new value, so the announcement is already spoken with the new setting. Numeric fields can also be typed directly.

Sections

  • Voice: gender metadata, P1/P2 pitch, pitch span, voicing, consonants, roughness, flutter, clarity, speed and echo.
  • Consonants: Designer macros plus the real standard eSpeak consonants and voicing values.
  • Formants 0-8: frequency, strength, width/damping and offset. In Klatt 6, F1-F6 frequency/offset and F1-F4 width are shared with the Klatt panel; Formant 0 and formant Strength belong to the standard formant synthesizer.
  • Breath: eight breath values and eight breath widths.
  • Tone: up to five frequency/amplitude points plus Dark/Bright, Body and Presence macros.
  • Klatt: Standard eSpeak or Klatt 6 / SpeechPlayer, global resonance damping, voicing, flutter, aspiration/Breath 1 and F1-F6 controls.
  • Stress Length, Stress Add, Stress Amp: the eSpeak stress levels that are currently used.
  • Metadata: age, author/maintainer, status, description, voice version, license and contact.
  • Internals and backends: advanced parser options and MBROLA controls. These are intentionally off until enabled.

Clarity

Clarity 0 through 4 progressively extends harmonic construction from F1 to F5. Value 5 keeps F1-F5 and uses squarer peaks. It mainly affects standard eSpeak formant synthesis.

Tone macros

The Tone macros exist only in the editor. They modify the real eSpeak tone frequency/amplitude points. A value of 128 is neutral. Saved voice files contain only standard eSpeak directives.

Variants and compatibility

The NVDA eSpeak variants selector uses NVDA’s live variant list and loads the installed eSpeak variant directly; it is not a copied variant library. Choosing one loads that clean source into the controls and then clears the selector, because native variants are starting points rather than editable project files. Ctrl+Delete still remembers that source as the current base. The Designer only creates a temporary runtime voice after you actually edit a parameter.

The main design rule is compatibility: a saved voice is a normal text eSpeak variant. Designer-only macros are baked into standard directives such as pitch, formant, consonants, voicing, breath, tone and klatt 6. The voice file can therefore be copied by itself into eSpeak/NVDA and used without this add-on.

Personal saves may also have a .editor.json sidecar. It stores editor-only macro positions so a project can be resumed accurately. It is optional and is not required to use the voice.

Saving and installing

Ctrl+S always opens Save As. Keeping the proposed name lets you overwrite the personal-library copy after confirmation; changing the name creates a new personal variant. Only a saved personal variant whose title does not show Modified can be installed with Ctrl+Shift+S. A factory/native eSpeak variant or the standard voice must therefore first be saved into the personal library with Ctrl+S. Editing a personal variant makes it Modified again until it is saved. Installation writes a compatible copy to NVDA's native espeak-ng-data\voices\!v folder and never overwrites an existing native/factory variant: if the requested name already exists, the new copy is installed with the next available number appended to its name. The Designer remains on the personal source after installation.

Languages

The interface and this guide are available in English, Italian, Spanish and French. Any other NVDA/system interface language falls back to English.

Transparent variant editing: when editing an installed or saved language variant, untouched source directives are preserved exactly. Only parameters you actually change are replaced in the working/saved file. This is especially important for Breath and Breath Width.
